## Rules

- Keep raw chat exports out of this repository.
- Record only a source locator, bounded scope and aggregation checkpoint.
- Detailed project chronology remains in the source project.
- Future audits append a new checkpoint only when meaningful new evidence has been aggregated.
- A source can be audited repeatedly; do not create fake new projects just to represent another batch.


## Access rule

Do not load source-project chronology during ordinary implementation.

Open the linked project history only when:
- auditing workflow quality;
- investigating why a current rule/architecture exists;
- extending the case-study aggregation;
- resolving a historical contradiction or dead end.
