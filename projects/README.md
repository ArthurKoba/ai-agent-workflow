# Project Prompt Sources

Project prompts are harness-level configuration sources.

They are **not** repository startup documents and ordinary agents should not reread them from Git.

Available sources:

- `reverse-engineering/PROJECT_PROMPT.md` — broad reverse-engineering / embedded / camera / firmware project.
- `infrastructure/PROJECT_PROMPT.md` — personal agent/development infrastructure project.

Each Project prompt selects authorities, tool surfaces and skill routing while the account prompt remains universal.
