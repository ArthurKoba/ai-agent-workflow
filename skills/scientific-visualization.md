# Scientific Visualizations — Editable Diagrams and Quantitative Charts

Use when creating, modifying, reviewing or exporting a scientific
chart, algorithm diagram, functional block scheme or research
figure. Preserve **editable source, genuine vector output and
reproducible numeric evidence** as distinct deliverables. The
selected notation, publication profile and project requirements
govern exact symbols, language, fonts and whether a junction
requires a dot.

Read only the relevant module completely:
- [Choose a real editable/source format](scientific-visualization/authoring.md)
  — flowcharts, electrical diagrams, numeric data and raster originals.
- [Build diagram topology and geometry](scientific-visualization/diagrams.md)
  — nodes, ports, connectors, branches, joins, crossings and returns.
- [Verify native and exported diagrams](scientific-visualization/verification.md)
  — per-edge checks, SVG/source parity, publication-scale inspection
  and final source handoff.
- [Reproducible charting](scientific-visualization/charts.md)
  — measured/model numbers, axes, units, spreadsheets, plots and SVG.

For experimental evidence, use the separate Scientific Experiments
Skill; for equation semantics, use Scientific Mathematics. This Skill
does not prove a research result from attractive presentation.
