
# Obsidian Graph Checklist

Перед завершением graph/wiki-правки проверить:

- нет реальных файлов с generic-именами `index.md`, `log.md`, `discussion.md`, `open-questions.md`;
- `wiki/wiki-log.md` связан из `wiki/wiki-index.md`;
- project-страницы связаны из своего `<project>-index.md`;
- shared-страницы связаны из `wiki/shared/shared-index.md`;
- meta-страницы связаны из `wiki/wiki-index.md` или meta-index;
- старые пути не остались в wiki-ссылках и graph JSON;
- актуальный JSON хранится в одном месте: `wiki/meta/obsidian-graph/obsidian-graph-current-json.md`;
- если внешний semantic index/cache индексирует wiki, после переименований обновить/очистить его по контракту используемого инструмента.
