# Obsidian Graph Maintenance

Use this optional subskill when maintaining an Obsidian Graph View, graph color groups, self-documenting wiki node names or orphan/broken-link cleanup.

## Read

1. `rules.md`
2. `checklist.md`
3. `examples.md` when naming/ownership is ambiguous

## Boundary

This subskill is presentation/navigation maintenance for a knowledge base. It does not own project facts, workflow policy or the knowledge-base operating model.

When a graph change also moves knowledge ownership, load the parent `../README.md` and the workflow context-maintenance protocol.
